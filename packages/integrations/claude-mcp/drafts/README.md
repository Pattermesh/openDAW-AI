# Drafts — open ideas (not yet scoped)

These are **drafts**: bigger, exploratory directions for the claude-opendaw toolbox. They're
intentionally not issues yet — they need design before they're buildable. If one excites you,
comment with an approach and we'll promote it to a tracked issue.

Distinction:
- **Issues** = scoped, ready-to-build (see the repo Issues tab).
- **Drafts** = open ideas, here, seeking a champion + a design.

| Draft | Idea |
|-------|------|
| [visualizer-tags.md](visualizer-tags.md) | Tag points mid-track to drive visualizer effects (Shadertoy) |
| [score-to-video.md](score-to-video.md) | Score music to a reference video — ads, trailers, background scores |
| [vocals-lyrics.md](vocals-lyrics.md) | Vocal tracks with lyrics + a lyrics preview tooltip |
| [video-channel.md](video-channel.md) | Load a video into a channel (Shadertoy-style toolbox) + quick export |

All AGPL, all open. Pitch freely.
